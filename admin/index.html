GitHub 연결

처음 한 번만 설정하면 됩니다.

  1. 1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. 2. Repository access: 이 홈페이지 저장소만 선택
  3. 3. Permissions: Contents → Read and write (선택: Pages → Read-only, 배포 상태 표시용)
  4. 4. 생성된 토큰(github_pat_…)을 아래에 붙여넣기

토큰은 관리자 비밀번호로 암호화되어 저장소의 admin/auth.json에 저장됩니다. 원문은 어디에도 저장되지 않습니다.
